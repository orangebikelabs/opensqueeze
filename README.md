# Open Squeeze has moved

This repository is archived and read-only. Open Squeeze now lives on Codeberg:

**https://codeberg.org/orangebikelabs/opensqueeze**

The project is in maintenance mode there. Expect compatibility fixes, bug fixes and
dependency updates, but no new feature work is planned.

- **Issues and pull requests:** please open them on Codeberg. This repository no longer accepts them.
- **New releases:** published on [Codeberg releases](https://codeberg.org/orangebikelabs/opensqueeze/releases).
  Older APKs stay available under this repository's
  [GitHub Releases](https://github.com/orangebikelabs/opensqueeze/releases).
- **Translations:** still handled on [Weblate](https://hosted.weblate.org/projects/open-squeeze/).
